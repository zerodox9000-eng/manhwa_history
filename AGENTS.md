# Purpose

Owns Aeon's durable, public AniList snapshot archive.

## Contract

- Daily snapshots live at `anilist/YYYY/YYYY-MM-DD.json.gz`.
- `manifest.json` is generated by `manhwa_db/scripts/snapshots/archiveAniListSnapshots.js`.
- Do not hand-edit generated snapshots or checksums.
- A corrected same-day source snapshot may replace that date's archive entry.
- The live frontend must not load this repository during normal use.
- Keep each day independently compressed so no yearly file approaches GitHub's per-file limits.

## Verification

Archive publication is valid only after every manifest entry passes compressed checksum, restored raw checksum, and size verification.
